# vm-sales-roi-microsite

## Dependencies

This page loads its libraries from CDNs. Every `<script>` and stylesheet `<link>` names an exact version and carries an `integrity` hash, so the browser refuses a file that changes.

- To upgrade a library, change the version in its URL and recompute the hash: `curl -sL <url> | openssl dgst -sha384 -binary | openssl base64 -A`, then prefix the result with `sha384-`.
